## Dataset & Table Creation

Unlike the Beginner SQL Project, this project uses two tables created manually using MySQL.

**Tables Created:**

1. `myntra1` – Contains Customer ID, Customer Name and Product Category.
2. `myntra2` – Contains Customer ID, Sub-Category and Product Price.

**Data Preparation:**

- Created both tables using CREATE TABLE.
- Inserted sample records using INSERT INTO.
- Used Customer ID as the common column to perform JOIN operations.

The dataset is created directly within the SQL script, so no external CSV file is required.

## How to Run This Project

1. Download the `Intermediate_SQL_Project.sql` file.
2. Open MySQL Workbench.
3. Execute the script to create and populate both tables.
4. Run the SQL queries to explore JOINs and Window Functions.
