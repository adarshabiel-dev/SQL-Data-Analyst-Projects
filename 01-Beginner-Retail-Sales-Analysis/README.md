# Retail Sales Analysis – MySQL

## Project Overview
This is a beginner-level SQL project focused on analyzing retail sales data using MySQL.

## Tools Used
- MySQL
- SQL

## Key Analysis
- Total Revenue
- Total Transactions
- Average Sales
- Customer Analysis
- Product Category Analysis
- Sales Trends

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- COUNT(), SUM(), AVG()
- LIMIT

## Dataset
Retail Sales CSV dataset imported into MySQL for analysis.

## Objective
To practice SQL queries and extract meaningful business insights from retail sales data.
