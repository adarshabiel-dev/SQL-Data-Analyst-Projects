# SQL Data Analyst Projects

## About This Repository

This repository showcases my practical SQL skills through Beginner and Intermediate-level projects using MySQL. The projects focus on analyzing retail sales data.

## Projects

### 01. Beginner Retail Sales Analysis

**Folder:** `01-Beginner-Retail-Sales-Analysis`

A beginner-level SQL project focused on analyzing retail sales data and understanding business performance.

**SQL Concepts Covered:**
- SELECT, WHERE and ORDER BY
- Aggregate Functions (SUM, COUNT, AVG, MIN, MAX)
- GROUP BY and HAVING
- LIMIT
- DISTINCT

**Business Analysis:**
- Total Store Revenue
- Number of Transactions
- Average Sales
- Highest and Lowest Sales
- Sales by Product Category
- Top 5 Highest-Spending Customers
- Customer Order Analysis
- Customer Age Analysis

### 02. Intermediate Retail Sales Analysis

**Folder:** `02-Intermediate-Retail-Sales-Analysis`

An intermediate-level SQL project focused on combining multiple tables and performing advanced data analysis using MySQL.

**SQL Concepts Covered:**
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- PARTITION BY
- ORDER BY

**Business Analysis:**
- Customer and Product Price Analysis
- Total Sales by Customer
- Ranking Customers by Spending
- Category-wise Customer Ranking
- Identifying Highest-Spending Customers
